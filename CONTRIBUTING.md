# Contributing

Thanks for helping build the most useful map of marketing-measurement resources. This list works only if it stays **genuinely useful and genuinely neutral** — that's also what makes it credible and citable.

## The rules that matter

1. **Factual and neutral.** Describe what a tool *is* and *does*, in one line. No superlatives ("best", "leading", "#1", "most accurate"), no marketing copy, no disparaging competitors. If an entry reads like an ad, it will be edited or declined — this applies to the maintainer's own entries too.
2. **Vendors are welcome — including competitors.** You may add your own tool. Add it in the right section, alphabetically, described the same neutral way as everything else.
3. **Earn the entry.** Link to something real and maintained — a repo, docs, a substantive resource. No dead links, no thin landing pages with nothing behind them.
4. **Right section, right order.** Place entries in the most specific section that fits; keep sections alphabetical where they already are.
5. **Disclose affiliation.** If you're adding your own product, say so in the PR description (not in the list entry).

## Format

```markdown
- [Name](https://link) — One factual sentence: what it is and what it does.
```

Mark a maintainer-affiliated entry with a trailing `*(Maintainer of this list.)*` so readers can see the relationship — same as the existing Lifesight entries.

## How to contribute

- **Add / edit an entry:** open a pull request.
- **Suggest something / report an issue:** open an issue (broken link, unfair description, missing category).
- One logical change per PR keeps review fast.

## Neutrality enforcement

The maintainer (Lifesight) commits to applying these rules to its own entries first. If you believe a Lifesight entry is self-promotional or a competitor is described unfairly, open an issue with the `neutrality:` prefix — those are treated as high priority.
